# Fermenta

An open, linked wine reference built as an Obsidian vault: grapes, regions, styles, producers and UK shops.

Open the folder in Obsidian and begin at `Home.md`. Everything is plain Markdown, so it also works in any editor and can be turned into a website.

## What is inside
- `Grapes`: grape cards
- `Regions`: countries and regions, with maps
- `Styles`: wine styles such as Champagne, Port and Orange wine
- `Producers`: major, notable and low intervention producers
- `Shops`: UK wine retailers
- `Templates`: note templates

## Theme and plugins
- The **Fermenta** theme is included. Choose it under Settings > Appearance > Themes. It comes in two palettes, Claret and Chablis.
- Turn on **Bases** under core plugins. The tables and maps need it.
- Install and enable the **Maps** community plugin for the region maps, **Explorer Sort** for the folder order, and **Omnisearch** for the search links on the home page. All three are included in `.obsidian/plugins`. Enable them under Settings > Community plugins.

## Contributing
Pull requests are welcome. Keep to the existing note layout, British spelling and no em dashes. Only add facts you are confident of.

## Optional: the live Home page

`Home.md` uses the Dataview community plugin for its live counts, random picks, quiz and charts. Install **Dataview** from Settings > Community plugins, then turn on **Enable JavaScript queries** in its settings. Everything else in the vault works without it.

## The website

The notes are also published as a website, rebuilt automatically from this repo on every push. The files that build it live in the hidden `.site` folder and `.github/workflows`. You can ignore them when writing notes.
