# Wine Cellar

A free, linked wine reference that you can browse in Obsidian. Grapes, regions, styles, producers and UK shops all link to each other, so you can start anywhere and follow your curiosity.

## Start here
- [[Grapes]]: one card per grape, with where it grows and what it tastes like.
- [[Wine Regions]]: countries and regions, with maps, climate, soils and key wines.
- [[Styles]]: things like Champagne, Port, Orange wine and Sherry, linked to the grapes and regions behind them.
- [[Producers]]: major houses, notable smaller growers and low intervention names.
- [[Shops]]: where to buy wine in the UK, from supermarkets to independents.

## How it fits together
- A **grape** links to the regions that grow it and the styles it makes.
- A **region** links to its grapes, styles and producers.
- A **style** links to its grapes and regions.
- A **producer** links to its regions, grapes and styles.
- Each page has a "Wines I've tried" section where your own tasting notes can appear.

## Using it
1. Download or clone this repository and open the folder as a vault in Obsidian.
2. Turn on Bases in the core plugins, which the tables and maps need.
3. Start from this page, or open any `.base` file to browse a whole section.

## Adding to it
Anyone is welcome to improve the vault. Fix a fact, add a producer, a grape or a shop, then send a pull request. Please keep to the same note layout as the existing pages, use British spelling, and only add things you are confident of. Everything here was written from general knowledge and should be checked before you rely on it.
